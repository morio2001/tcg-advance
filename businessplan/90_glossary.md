# 用語集 — businessplan/ で使う横文字

> 事業計画ドキュメントに出てくる用語を、この事業に即して説明する。
> 新しい用語を使ったドキュメントを書いたら、ここに追記する運用。

| 用語 | 意味 | この事業では |
| --- | --- | --- |
| **CAC** (Customer Acquisition Cost) | ユーザーを1人獲得するのにかかったコスト | イベント事業の現場でアプリを入れてもらえば、収益を上げながらCACほぼ0円で獲得できる（「イベント事業=CAC装置」の意味） |
| **GTM** (Go-To-Market) | 最初の客をどこで・どうやって獲るかの作戦 | 仲のいいショップ連携+大型大会協賛で初期1,000人。エリアは絞る。「GTMエリア」=最初に集中攻略する地域 |
| **PMF** (Product Market Fit) | プロダクトが市場にハマり、使い続けられる状態 | 初期1,000人の4週後残存率とログ相互確認率で判定（`10_` §8 Stage 1） |
| **リテンション** | ユーザーが離脱せず使い続けること | バッジ・ランキング・週内サイクル（`11_` `12_`）は全部このため |
| **North Star Metric** | 事業全体の健康を1つで示す最重要指標 | 週次の対戦ログ作成数（相互確認済み比率を併記） |
| **KPI** | 目標達成度を測る数値指標 | 4週残存率、ログ相互確認率、claim店舗数など |
| **CRM** (Customer Relationship Management) | 顧客管理（ツール） | ショップが常連の来店・参加を管理分析できるツール。Stage 3でSaaSとして販売 |
| **SaaS** (Software as a Service) | 月額課金で使ってもらうソフトウェア | 上のCRMをショップにサブスク販売する形態 |
| **MRR** (Monthly Recurring Revenue) | 月次の継続収益（サブスク売上合計） | 月額パス・CRM SaaSが育つと積み上がる数字 |
| **eCPM** | 広告表示1,000回あたりの収益単価 | 「リワード広告は柱にしない」の判断根拠（下落傾向のため） |
| **claim** | 店舗ページを店主本人が引き取って編集権を得ること | 「ビジネスオーナーですか？」導線。Googleビジネスプロフィール（GBP）と同じ仕組み |
| **GBPモデル** | Googleビジネスプロフィール方式: 運営が情報を先に載せ、事業者が後からclaimする | イベント・店舗情報は運営が集約掲載し、ショップに載せる作業をさせない（`12_` §0） |
| **TAM / SAM / SOM** | 市場規模の3段階: 理論上の最大 / 現実に狙える範囲 / 実際に取れる見込み | TCG市場3,024億円は背景。取れる市場はツール・サブスク・イベント支出（`10_` §3） |
| **オンボーディング** | 初回起動から価値を体験するまでの導線 | 初回起動→初ログ作成を1分以内に（`20_` §4.4） |
| **フライホイール** | 各事業が互いを強化して勝手に回り出す構造 | イベント→アプリ→メディア→収益→再投資の循環（`10_` §2） |
| **LIFF** | LINE内で動くミニアプリの仕組み | 検討したが不採用（LINE通知が従量課金のため）。複垢対策は本人認証ゲートで行う |
| **PWA** | ブラウザ技術で作るホーム画面追加可能なアプリ | 現在の形態。早期にネイティブアプリ化想定（通知のため） |
