# businessplan/ — 事業計画

TCG Advance の事業計画を管理するディレクトリ。別の Claude セッション（事業計画検討用）と
開発セッションがこのリポを介して内容を共有するためのハブでもある。

## 構成ルール

| ファイル | 役割 | 更新者 |
| --- | --- | --- |
| `00_current-state.md` | リポの現状から読み取れる事業・プロダクトの棚卸し | 開発セッション（実装が進んだら更新） |
| `10_business-plan.md` | 事業計画本体（ここにアップしていく） | オーナー / 事業計画セッション |
| `2x_*.md` 以降 | 事業計画からのブレイクダウン（収益モデル、GTM、KPI、機能要件など） | 各セッション |

- 番号プレフィックスは上流→下流の順。上流が変わったら下流を見直す
- 事業計画側の決定は `10_` に、そこから開発に落ちる要件は `2x_` を経由して実装へ
- プロダクトの画面・トンマナは [`../design/`](../design/)、機能一覧は `../feature_list.xlsx` を参照
