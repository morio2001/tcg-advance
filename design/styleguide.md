# TCG Advance デザインスタイルガイド

新しい画面モックを作るときのトンマナ定義。既存画面から抽出した「正」であり、
モック作成時（Claude / claude.ai どちらでも）はこのファイルと `screenshots/` を渡すこと。

## レイアウト

- **モバイル縦固定**: 最大幅 `430px`、中央寄せ（`margin: 0 auto`）、高さ `100vh`
- 下部に固定タブバー（ホーム / イベント / 戦績 / デッキ / 検索 / アカウント）、コンテンツ側は `paddingBottom: 70px`
- ページタイトルは左上に大きく（20〜24px, bold）、アクセントカラーで
- スタイリングは **インライン style オブジェクト**（CSSフレームワーク不使用）。グローバルは `src/index.css` のみ

## カラー

| 役割 | 値 |
| --- | --- |
| 背景 | `linear-gradient(180deg, #0a0e1a 0%, #0d1220 50%, #0a0e1a 100%)` |
| 基本テキスト | `#e0e8f0` |
| セカンダリテキスト | `#8899aa` / `#c0d0e0` |
| 弱いテキスト・非アクティブ | `#556677` |
| ボーダー | `#334455` 系、または `rgba(0,224,224,0.15)` の半透明シアン |
| **プライマリアクセント（シアン）** | `#00e0e0`（タブ選択・タイトル・強調） |
| 成功・ポジティブ | `#00c878` |
| 警告・XP・ゴールド | `#ffc800` |
| エラー・敗北 | `#ff5050` / `#c04040` |
| 紫アクセント（レア・特別） | `#a064ff` |
| 青アクセント | `#00a0ff` / `#4080d0` |

TCGタイトル別カラーは `src/data/mockData.ts` の `TCG_GAMES` を参照（ポケカ `#e83030`、MTG `#c8a040` など）。

## タイポグラフィ

- フォント: `'Noto Sans JP', -apple-system, sans-serif`
- 本文 13〜14px / キャプション 10〜11px / 見出し 16〜24px
- 強調は `fontWeight: 600〜700` ＋ カラーで行う（サイズを上げすぎない）

## コンポーネント

- カード: 半透明の暗い面 ＋ 細ボーダー ＋ `borderRadius: 10〜16px`、`padding: 10〜16px`
- タグ/バッジ: `Tag`（`src/components/Shared.tsx`）— 小さめ角丸、`rgba` 背景 ＋ 同系色テキスト
- セクション見出し: `SectionHeader` — タイトル＋件数＋アイコン
- イベント行: `EventCard`
- 未実装画面: 🚧 絵文字＋「現在開発中です」の `UnderConstruction`（`App.tsx`）

新規モックでも **まず `Shared.tsx` の既存コンポーネントを使い回し**、足りないものだけ追加する。

## データ

画面に流すダミーデータは `src/data/mockData.ts` に集約されている
（デッキ・イベント・戦績・対戦相手・ソーシャル投稿・チャレンジ等、型は `src/types/index.ts`）。
新しい画面のモックデータも原則ここに追加する。

## モック開発の回し方

```bash
npm run dev:mock   # Supabase なしで起動（VITE_MOCK_AUTH=1、モックユーザーでログイン済み状態）
npm run shots      # 全タブのスクショを design/screenshots/ に書き出し
```

- モックモードの実体は `src/lib/mockMode.ts`（モックユーザー／プロフィール定義）
- 画面が増えたら `scripts/capture-screens.mjs` の `TABS` に撮影対象を追加する
- 実装がマージされたら `npm run shots` でスクショを更新してコミットする（デザインの現状同期）
